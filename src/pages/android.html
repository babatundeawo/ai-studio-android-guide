This page covers installing your deployed web app as a PWA — the path this guide is built around, and it works no matter which host you used in Part 4 or 4B. If you instead used AI Studio's Build an Android app mode (see Part 2) to generate a native Kotlin app, you install that one differently: through Google Play's Internal Test track link, or as a downloaded APK — there's no PWA install step for that path.
17
Open in Chrome
Open Chrome on your Android device (not other browsers — Chrome has the most reliable PWA support). Navigate to your live URL (Vercel, Replit, or Cloud Run — whichever you deployed to) and wait for the page to fully load.
18
Install the App
Auto prompt: Tap "Install app" if a banner appears. Manual: Tap ⋮ menu → "Add to Home screen" or "Install app" → confirm. Takes 2–5 seconds.
19
Launch & Test
Find your icon on the home screen (labeled with your manifest's short_name). Tap it — the app opens in standalone mode with no browser address bar.
20
App Drawer Access
Your app also appears in the Android app drawer (swipe up from home). Long-press the icon for more options (uninstall, app info, move).
Chrome's menu wording varies slightly by Android version. You may see "Install app," "Add to Home screen," or a combined install sheet with both "Install" and "Create shortcut" options — pick Install for the full standalone-app experience with an app-drawer entry; "Create shortcut" just opens the site in a browser tab.
You now have a fully functional AI-powered Android app! Share your live URL with anyone — they can access it in a browser or install it just like you did.
