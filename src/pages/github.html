  3. Export Your App to GitHub

    In AI Studio's Code/Preview pane, look for the GitHub icon (cat silhouette) in the header bar and click it, this opens the Push to GitHub panel (you may also see it called "Sync with GitHub"). The first time, authorize Google AI Studio's GitHub app when prompted. Set a repository name (lowercase + hyphens, e.g. my-ai-app), set visibility to Public, and confirm.

    You'll see a confirmation once the initial commit lands in your new repository. After this first push, AI Studio keeps a sync link to that same repo, so later updates in Part 6 push to it directly rather than creating a new one each time, worth double-checking, since some users have reported the sync occasionally lagging behind; if a later push doesn't show up on GitHub, re-open the GitHub panel and push again.

    Your API key does not travel with the export. For security, AI Studio does not copy your GEMINI_API_KEY secret into the GitHub repo. You'll add it manually as an environment variable in Vercel in the next part, that's expected, not a bug.

  4. Verify Your GitHub Repository

    Checklist

    Go to github.com and open your new repository. Confirm these files exist:

    your-app-repo/ │ ├── index.html ← MUST have script tag + manifest link ├── manifest.json ← MUST exist with name, colors, icon ├── index.tsx or main.tsx. React entry point ├── package.json Node.js dependencies ├── vite.config.ts Build config ├── src/ Source code └── public/ Static assets
    If index.html or manifest.json are missing or incorrect, edit them directly on GitHub (pencil icon on the file page) before deploying to Vercel.
