Three routes lead to the same installable app. Pick one, then continue to Part 5.

RouteGood fit whenLimits to knowUpdating later
Publish from AI StudioCloud Run Starter TierYou want the fastest path to a live HTTPS URL, with no GitHub or host account.First two apps only, one Cloud Run region, and not available if you've ever set up Google Cloud billing.Publish again from AI Studio.
VercelPart 4You want automatic redeploys on every GitHub push.The free Hobby plan is for non-commercial use only.Automatic after each GitHub push.
ReplitPart 4BYou may charge for your app, or want everything in one dashboard.The key is baked into a static build, so restrict it in Google AI Studio.Pull the changes and click Deploy again.

Before you begin

  • Stable internet connection
  • Chrome, Firefox, Safari, or Edge
  • Android phone (optional)
  • 45–60 mins of focused time
  • Basic instruction-following ability
  • No child accounts on any service
Security rulesNever share API keys publicly. Save all credentials in a password manager (1Password, Bitwarden, or your browser's built-in manager).
