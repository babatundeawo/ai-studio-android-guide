Known Issue: When you update your app in AI Studio and export to GitHub again, the agent can occasionally regenerate index.html without the critical <script> tag or manifest link. This causes a blank page. The SOP below prevents it.
1

Make Changes in AI Studio

Update your app's features, AI behaviour, or interface by chatting with the Build agent or editing code directly. Test thoroughly in the live preview before doing anything else.

2

Re-check Critical Files in AI Studio — BEFORE Exporting

Verify index.html still has the script tag. If missing, add it back now:

Also verify manifest.json is still present and correct.

3

Export to GitHub

Click "Export to GitHub" in AI Studio. Wait for the commit confirmation before proceeding.

4

Verify on GitHub (If Unsure)

Open your repo and check index.html. If the script tag is missing, edit the file directly on GitHub, add it back, and commit with: Restore script tag after AI Studio update

5

Wait for Auto-Deploy (1–2 min)

Vercel or Netlify/Cloudflare Pages detect the commit and automatically rebuild (Replit needs a manual re-deploy click — see Part 4B). Monitor progress in your host's dashboard. Your installed Android app will reflect the update after a refresh or restart — Chrome updates installed PWAs in the background on a normal cache cycle.
